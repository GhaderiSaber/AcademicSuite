# APA 7 Typography & Table Specs

1. **Table Borders**:
   - Exactly 3 horizontal borders: Top (0.75 pt), Header bottom (0.5 pt), Table bottom (0.75 pt).
   - Zero vertical borders.
2. **Persian Leading Zero**:
   - Always retain leading zeros: `۰.۰۰۱`, `۰.۰۵`, `۰.۸۵`. Never write `.۰۰۱` or `.۰۵`.
3. **Decoupled Numbers**:
   - Decouple numeric table cells to LTR (`rtl="0"`) with Latin font (`Times New Roman`) so minus signs precede numbers ($-0.32$).
