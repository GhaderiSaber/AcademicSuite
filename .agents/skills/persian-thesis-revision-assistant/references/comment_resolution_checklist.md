# Supervisor Comment Resolution Checklist (چک‌لیست رفع کامنت‌ها و تحویل نهایی رساله)

Before re-submitting the revised thesis or proposal to the supervisor (استاد راهنما) or defense jury (هیئت داوران), verify that every point on this checklist is satisfied.

---

## 1. Comment Tracking & Completeness

- [ ] **100% Comment Coverage**: Every single comment in the Word file or feedback letter has a dedicated row in the Response Table (`جدول_پاسخ_به_نظرات_اساتید.docx`).
- [ ] **Author Attribution**: If multiple professors reviewed the thesis (e.g., استاد راهنما، استاد مشاور، داور داخلی، داور خارجی), each comment clearly identifies who requested the change.
- [ ] **Exact Page Numbers**: All page and paragraph numbers mentioned in the Response Table correspond accurately to the **final version** of the thesis document (not the old pre-revision draft).
- [ ] **Clear Distinctions**: Responses clearly state what exact text was added, deleted, or rephrased.

---

## 2. Textual & Theoretical Revisions

- [ ] **New Citations in Bibliography**: If new studies or authors were added to Chapters 1, 2, 3, 4, or 5 in response to feedback, their complete citations have been added to the **References / منابع و مآخذ** section.
- [ ] **Cross-Chapter Consistency**: If a variable definition, instrument name, or sample size was modified in Chapter 1 or 3, verify that the same changes were reflected in Chapters 4 and 5.
- [ ] **Persian Half-Spaces (نیم‌فاصله)**: All newly drafted paragraphs preserve the Persian zero-width non-joiner (`\u200c`).

---

## 3. Statistical & Methodological Integrity

- [ ] **Assumption Tests Reported**: If the supervisor asked for normality or homoscedasticity, the exact $W$, $F$, and $p$-values from `statistical-data-analyst` are reported.
- [ ] **APA 7 Compliance**: All revised tables adhere to the 3-line borderless standard (no vertical borders, italicized statistics $M, SD, t, F, p$).
- [ ] **No Decimal Mismatches**: The values cited in the Chapter 5 discussion match the tables in Chapter 4 down to the exact decimal point.

---

## 4. Final Submission Deliverable Package

A defense-ready revision package for the supervisor includes:
1. **`رساله_نهایی_اصلاح_شده.docx`** (Clean final thesis with all revisions integrated and Track Changes accepted).
2. **`رساله_با_تغییرات_برجسته.docx`** (Optional: Tracked-changes or highlighted version showing revisions in color for quick supervisor scanning).
3. **`جدول_پاسخ_به_نظرات_استاد_راهنما_و_داوران.docx`** (The formal point-by-point response table).
