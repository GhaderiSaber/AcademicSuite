# Regression Modeling & APA 7 Reporting Rules

## 1. Table Requirements
- Model Summary: $R, R^2, \text{Adjusted } R^2, F, p$.
- Coefficients: Unstandardized $B$, Standard Error $SE$, Standardized $\beta$, $t$, $p$.
- Collinearity: Tolerance ($> .20$), VIF ($< 5.0$).

## 2. Statistical Notation
- Italicize Latin symbols (*R², F, B, SE, t, p*). Greek $\beta$ remains regular.
- Report $p < .001$ instead of $.000$.
