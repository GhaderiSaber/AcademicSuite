# Qualitative Data Analyst Skill (تحلیل داده‌های کیفی و نگارش فصل چهارم)

This skill empowers Antigravity to act as an elite qualitative research methodologist and reporting specialist. It conducts rigorous, publication-grade qualitative data analysis adhering to **APA 7 JARS-Qual (Journal Article Reporting Standards for Qualitative Research)**, specializing in:
1. **Braun & Clarke (2006, 2019, 2021) Reflexive Thematic Analysis (تحلیل تم رفلکسیو / تحلیل مضمون)**
2. **Strauss & Corbin (1990, 1998) Systematic Grounded Theory (گراندد تئوری / نظریه داده‌بنیاد)**
3. **Lincoln & Guba (1985) Trustworthiness Framework (معیارهای باورپذیری و اعتمادپذیری)**
4. **Inter-Coder Reliability & Agreement (پایایی بازآزمون و پایایی میان‌کدگذاران با فرمول هلستی و کاپا)**

---

## 1. When to Activate This Skill

Activate this skill when:
1. The user asks to analyze qualitative research data from interviews (مصاحبه‌های نیمه‌ساختاریافته), focus groups (گروه‌های کانونی), field notes, or textual documents.
2. The user requests drafting **Chapter 4 of a qualitative thesis/dissertation (فصل چهارم پایان‌نامه/رساله کیفی)** in psychology, counseling, social sciences, or healthcare.
3. The user needs to construct a **Thematic Network (شبکه مضامین Attride-Stirling)** with 3 levels: Basic Themes (مضامین پایه), Organizing Themes (مضامین فراگیر / سازمان‌دهنده), and Global Themes (مضامین اصلی / فراگیر).
4. The user conducts a **Grounded Theory study (نظریه داده‌بنیاد)** requiring open coding (کدگذاری باز), axial coding (کدگذاری محوری), selective coding (کدگذاری انتخابی), and Strauss & Corbin's **Paradigmatic Model (مدل پارادایمی ۶ بعدی)**.
5. The user needs to calculate **Inter-Coder Reliability (پایایی کدگذاران)** using Holsti's Coefficient of Reliability ($PAO$) or Cohen's Kappa ($\kappa$).
6. The user needs a multi-sheet **Qualitative Coding Matrix (ماتریس کدگذاری در اکسل)**, high-resolution conceptual diagrams (300 DPI), or defense-ready Persian/English Word reports (`.docx`).

## 3. Core Methodological Standards

### Track A: Reflexive Thematic Analysis (Braun & Clarke, 2006, 2021)
- **Phase 1: Familiarization with Data** (آشنایی با داده‌ها): Reading and re-reading transcripts, noting initial impressions.
- **Phase 2: Generating Initial Codes** (تولید کدهای اولیه): Systematic inductive or deductive coding across the entire corpus.
- **Phase 3: Searching for Themes** (جستجوی تم‌ها): Collating codes into potential candidate themes.
- **Phase 4: Reviewing Themes** (بازبینی تم‌ها): Checking candidate themes against coded extracts and the whole data set.
- **Phase 5: Defining and Naming Themes** (تعریف و نام‌گذاری تم‌ها): Generating clear definitions and conceptual names.
- **Phase 6: Producing the Report** (تدوین گزارش پایانی): Weaving together analytic narrative and illustrative verbatim quotes.
- **3-Tier Hierarchy (شبکه مضامین)**:
  - **Basic Themes (مضامین پایه)**: Lowest-order premises, direct semantic/latent codes.
  - **Organizing Themes (مضامین سازمان‌دهنده)**: Middle-order clusters that group basic themes into coherent conceptual units.
  - **Global Themes (مضامین فراگیر)**: Super-ordinate macro themes encompassing the core meaning of the phenomenon.

### Track B: Grounded Theory Paradigmatic Model (Strauss & Corbin, 1990, 1998)
1. **Core Phenomenon (پدیده محوری / مقوله هسته)**: The central idea, event, or problem around which actions are centered.
2. **Causal Conditions (شرایط علی)**: Specific factors, events, and triggers that give rise to the core phenomenon.
3. **Context (بستر و زمینه)**: The specific set of conditions, spatial/temporal settings, and background environment.
4. **Intervening Conditions (شرایط مداخله‌گر)**: Broad structural, sociocultural, and institutional conditions facilitating or constraining strategies.
5. **Action/Interaction Strategies (راهبردها و تعاملات)**: Purposive actions, coping mechanisms, and behavioral tactics implemented by participants.
6. **Consequences (پیامدها)**: Direct and indirect results, emotional, relational, or functional outcomes of the strategies.

### Track C: Rigor, Trustworthiness & Inter-Coder Reliability
- **Lincoln & Guba (1985) Trustworthiness Audit**:
  - **Credibility (باورپذیری)**: Prolonged engagement, member checking (بازبینی توسط مشارکت‌کنندگان), peer debriefing.
  - **Transferability (انتقال‌پذیری)**: Thick description (توصیف عمیق و غنی), purposive sampling.
  - **Dependability (اعتمادپذیری / قابلیت اطمینان)**: External audit, standardized coding protocols, inter-coder checks.
  - **Confirmability (تأییدپذیری)**: Audit trail, reflexivity (بازاندیشی پژوهشگر), triangulation.
- **Holsti's Percentage Agreement Formula**:
  $$PAO = \frac{2M}{N_1 + N_2}$$
  - $M$: Number of identical agreements between coder 1 and coder 2.
  - $N_1, N_2$: Total number of codes assigned by coder 1 and coder 2.
  - Acceptance threshold: $PAO \ge 0.70$ (in social sciences, $\ge 0.80$ is excellent).
- **Cohen's Kappa ($\kappa$)**:
  $$\kappa = \frac{P_o - P_e}{1 - P_e}$$
  - Corrects for agreement occurring purely by chance ($P_e$).
  - Interpretation: $0.61 - 0.80$ Substantial, $> 0.80$ Near Perfect.

## 4. Execution Workflow

### Step 1: Ingest or Structure the Qualitative Payload
The engine accepts structured research payloads (`payload.json`) conforming to either Thematic Analysis or Grounded Theory schemas:
- Participant demographics (`participants`: array of objects).
- Methodological specifications (`method`: `"thematic_analysis"` or `"grounded_theory"`).
- Coded themes or paradigmatic dimensions (`themes` or `paradigmatic_model`).
- Verbatim quotations linked to participants (`quotes`: array with text, code, participant ID).
- Reliability data (`reliability`: agreements, total codes, Kappa).
- Lincoln & Guba audit procedures (`trustworthiness`: credibility, transferability, dependability, confirmability).

### Step 2: Execute the Automated Engine
Run `qualitative_engine.py` via CLI:
```bash
python3 .agents/skills/qualitative-data-analyst/scripts/qualitative_engine.py \
  --json path/to/qualitative_payload.json \
  --out-dir path/to/output_directory \
  --lang fa
```

### Step 3: Inspect Multi-Modal Deliverables
The engine deterministically generates 4 synchronized artifacts:
1. `فصل_چهارم_یافته‌های_کیفی.docx` (or `Chapter_4_Qualitative_Findings.docx`):
   - Strict APA 7th Edition styling and Iranian university dissertation formatting.
   - Genuine Word Right-to-Left (RTL) `<w:bidi w:val="1"/>` paragraph and `<w:bidiVisual/>` table elements.
   - B Nazanin 13pt body font, B Titr bold headings, Times New Roman for Latin text.
   - Formatted APA 7 summary tables: Participant Demographics, Master Theme Matrix, and Trustworthiness Audit.
   - Styled blockquotes for participant verbatim excerpts (indented 0.4 inches with italic styling and participant identifiers).
2. `thematic_matrix.xlsx`:
   - 5 professional sheets: `Summary & Metrics`, `Theme Hierarchy / GT Model`, `Participant Profiles`, `Verbatim Quotes`, and `Trustworthiness & Reliability`.
   - Navy header styling, frozen panes, and auto-adjusted column widths.
3. `thematic_network.png`:
   - High-resolution (300 DPI) publication-ready conceptual diagram visualizing the thematic network or grounded theory paradigmatic model.
4. `qualitative_summary.json`:
   - Machine-readable synthesis containing all frequency metrics, hierarchy mappings, and reliability coefficients.

## 6. Persian Academic Writing Rules for Qualitative Research

- **Terminology Consistency**:
  - Global Theme $\to$ مضمون فراگیر / تم اصلی
  - Organizing Theme $\to$ مضمون سازمان‌دهنده / تم میانی
  - Basic Theme $\to$ مضمون پایه / کد اولیه
  - Trustworthiness $\to$ اعتمادپذیری و قابلیت اعتماد
  - Credibility $\to$ باورپذیری / قابلیت پذیرش
  - Transferability $\to$ انتقال‌پذیری
  - Dependability $\to$ اعتمادپذیری / پایداری
  - Confirmability $\to$ تأییدپذیری
  - Member Checking $\to$ بازبینی توسط مشارکت‌کنندگان
  - Thick Description $\to$ توصیف غنی و عمیق
  - Theoretical Saturation $\to$ اشباع نظری
  - Inter-Coder Agreement $\to$ توافق میان‌کدگذاران
- **Half-space (نیم‌فاصله)**: Strictly enforce standard Persian half-spaces (`\u200c`) in compound words (e.g., `مشارکت‌کنندگان`, `سازمان‌دهنده`, `کدگذاری`, `یافته‌های`).
- **Verbatim Citations**: Participant excerpts must cite the anonymous code in brackets (e.g., `(مشارکت‌کننده شماره ۳، زن، ۴۲ ساله)`).
