# Hu & Bentler (1999) 11 Fit Indices Standard

| Fit Index | Threshold (Good Fit) | Threshold (Acceptable) |
|---|---|---|
| $\chi^2/df$ | $< 2.0$ | $< 3.0$ |
| **CFI** | $\ge .95$ | $\ge .90$ |
| **TLI** | $\ge .95$ | $\ge .90$ |
| **RMSEA** | $< .06$ (90% CI) | $< .08$ |
| **SRMR** | $< .08$ | $< .10$ |
