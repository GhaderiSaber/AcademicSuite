# واژه‌نامه تخصصی روش پژوهش و آمار
## Methodology & Statistics Bilingual Glossary

این واژه‌نامه معادل‌های دقیق اصطلاحات طرح تحقیق، روان‌سنجی، متغیرها و آزمون‌های آماری را پوشش می‌دهد.

| English Term | معادل استاندارد فارسی | توضیحات و فرمول‌ها / علائم |
| :--- | :--- | :--- |
| **Sample / Sample Size** | نمونه / حجم نمونه | $N$ یا $n$ |
| **Target Population** | جامعه آماری هدف | |
| **Sampling Method** | روش نمونه‌گیری | تصادفی، خوشه‌ای، در دسترس، هدفمند |
| **Convenience Sampling** | نمونه‌گیری در دسترس | |
| **Cluster Sampling** | نمونه‌گیری خوشه‌ای | |
| **Stratified Random Sampling** | نمونه‌گیری تصادفی طبقه‌ای | |
| **Cross-sectional Study** | مطالعه مقطعی | |
| **Longitudinal Study** | مطالعه طولی | |
| **Correlational Study** | مطالعه همبستگی | |
| **Experimental Design** | طرح آزمایشی | پیش‌آزمون - پس‌آزمون با گروه کنترل |
| **Independent / Dependent Variable** | متغیر مستقل / وابسته | |
| **Mediating Variable (Mediator)** | متغیر میانجی | اثر غیرمستقیم |
| **Moderating Variable (Moderator)** | متغیر تعدیل‌کننده | اثر تعاملی |
| **Confounding Variable** | متغیر مخدوش‌کننده / مزاحم | |
| **Reliability** | پایایی / قابلیت اعتماد | |
| **Internal Consistency** | همسانی درونی | |
| **Cronbach’s Alpha** | ضریب آلفای کرونباخ | $\alpha$ |
| **Test-Retest Reliability** | پایایی بازآزمایی | |
| **Validity (Construct, Convergent, Discriminant)** | روایی (سازه، همگرا، واگرا / تشخیصی) | |
| **Content Validity** | روایی محتوایی | |
| **Factor Analysis (EFA / CFA)** | تحلیل عاملی (اکتشافی / تأییدی) | |
| **Structural Equation Modeling (SEM)** | مدل‌سازی معادلات ساختاری | |
| **Path Analysis** | تحلیل مسیر | |
| **Mean and Standard Deviation** | میانگین و انحراف استاندارد | $M \pm SD$ |
| **Descriptive Statistics** | آمار توصیفی | |
| **Inferential Statistics** | آمار استنباطی | |
| **Bivariate Correlation** | همبستگی دومتغیره (ساده) | ضریب پیرسون ($r$) یا اسپیرمن |

| **Zero-order Correlation** | همبستگی مرتبه صفر | همبستگی بدون کنترل هیچ متغیری |
| **Multiple Regression** | رگرسیون چندگانه | ضرایب $\beta$ و $R^2$ |
| **Stepwise / Hierarchical Regression** | رگرسیون گام‌به‌گام / سلسله‌مراتبی | |
| **Analysis of Variance (ANOVA)** | تحلیل واریانس یک‌راهه | آماره $F$ |
| **Multivariate ANOVA (MANOVA)** | تحلیل واریانس چندمتغیره | لاندای ویلکز |
| **Analysis of Covariance (ANCOVA)** | تحلیل کوواریانس | |
| **Independent Samples t-test** | آزمون تی مستقل (برای دو گروه مستقل) | آماره $t$ |
| **Paired Samples t-test** | آزمون تی همبسته / زوجی | |
| **Significance Level / p-value** | سطح معناداری | $p < .05$, $p < .01$, $p < .001$ |
| **Effect Size** | اندازه اثر | کوهن $d$ یا اتا مجذور جزئی $\eta_p^2$ |
| **Norms & Cut-off Points** | هنجارها و نقاط برش بالینی | مقادیر مرزی غربالگری |
| **Goodness-of-fit Indices** | شاخص‌های برازش مدل | RMSEA, CFI, TLI, GFI |
