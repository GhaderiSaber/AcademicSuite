# واژه‌نامه تخصصی روان‌شناسی و علوم رفتاری
## Psychology & Behavioral Sciences Bilingual Glossary

این واژه‌نامه راهنمای معادل‌های استاندارد دانشگاهی در روان‌شناسی، روان‌پزشکی، علوم اعصاب و رفتارهای پرخطر/اعتیادهای فناورانه است.

| English Term | معادل استاندارد فارسی | توضیحات و کاربرد |
| :--- | :--- | :--- |
| **Problematic Internet Use (PIU)** | استفاده مشکل‌آفرین از اینترنت | کاربرد مکرر در مقالات اعتیاد به اینترنت |
| **Internet Gaming Disorder (IGD)** | اختلال بازی اینترنتی | طبق طبقه‌بندی DSM-5 |

| **Tolerance to Ambiguity** | تحمل ابهام | متضاد عدم تحمل ابهام |
| **Impulsivity / Impulsiveness** | تکانشگری | شامل خرده‌مقیاس‌های حرکتی، شناختی، و بی‌برنامگی |
| **Risk-taking Behavior** | رفتار خطرپذیری / رفتارهای پرخطر | |

| **Salience** | برجستگی / اشتغال ذهنی | مؤلفه اعتیاد رفتاری |
