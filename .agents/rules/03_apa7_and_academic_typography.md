# APA 7th Edition & Academic Typography Specification (Directive 4)

Comprehensive reporting standards for academic text, tables, and statistics across AcademicSuite deliverables.

## 1. Directive 4: Statistical Typography
- **Latin Symbols**: Italicize Latin statistical symbols:
  *M, SD, t, F, p, r, R², β, B, z, SE, d, df, n, N*.
- **Greek Letters**: Greek letters remain upright and regular:
  $\alpha, \beta, \eta^2, \chi^2, \lambda$.
- **Decimal Precision**:
  - Means, standard deviations, test statistics ($t, F, \chi^2$), correlations ($r$), and coefficients: Exactly **2 decimal places** (e.g., $M = 24.35, SD = 4.12, F(1, 148) = 12.45$).
  - Significance levels ($p$-values): Exactly **3 decimal places** (e.g., $p = .024$, $p = .003$).

## 2. Persian Leading Zero Standard (Strict Invariant)
- In Persian academic reporting, **NEVER omit the leading zero**.
  - Correct: `۰.۰۰۱`, `۰.۰۵`, `۰.۳۴`
  - Prohibited: `.۰۰۱`, `.۰۵`, `.۳۴`
- Report $p < .001$ in English, and $p < ۰.۰۰۱$ in Persian.
- Reporting $p = .000$ or $p = ۰.۰۰۰$ is strictly prohibited under APA 7 standards.

## 3. Table Formatting Standards
- Every APA 7 table must feature exactly **three horizontal borders**:
  1. Table top border (0.75 pt)
  2. Table header bottom border (0.50 pt)
  3. Table bottom border (0.75 pt)
- **Zero vertical borders**: Vertical lines inside academic tables are strictly prohibited.
- Table title must be descriptive, italicized, and placed above the table.
- Explanatory notes ($*p < .05, **p < .01, ***p < .001$) must appear below the bottom border.
