## 1. Constitutional Definition of the Skill Layer ("The Hands")

In the target architecture, **Skills are strictly modular runbooks, schemas, and deterministic execution wrappers**. 

### The Skill Boundary Invariants:
1. **Zero Orchestration in Skills**: A skill must never define multi-agent pipelines, coordinate subagents, or dictate high-level study progressions. All orchestration resides strictly in Layer 1 Durable Agents (`digital-saber` and `academic-orchestrator`).
2. **Stateless Execution**: Skills operate without persistent internal memory. They receive explicit input parameters (paths to `.xlsx`, `.json`, `.docx`), execute deterministic CLI tools, and return structured output payloads.
3. **Single-View Invariant (Directive 18)**: Every `SKILL.md` must be ingestible in a single `view_file` call:
   - Line Limit: $\le 500$ lines.
   - Size Limit: $\le 40,000$ bytes.
   - Extended specifications and rubrics must be placed in `references/`.

## 2. Refactoring Specification: `academic-suite-orchestrator`

The baseline audit identified that `.agents/skills/academic-suite-orchestrator/scripts/orchestrator_cli.py` (927 lines, 49,334 bytes) contains severe architectural leaks:
- It hardcodes 6 complete research pipelines (`thesis_empirical`, `scale_validation`, `qualitative_study`, `meta_analysis`, etc.).
- It silently falls back to `default_sample` across 17 skills when input data is omitted.
- It duplicates the responsibilities of the Antigravity Lead Agent.

### 2.1 Decoupling & Refactoring Plan
1. **Extract Pipeline Presets into Agent Logic**:
   - Pipeline preset definitions are removed from `orchestrator_cli.py` and converted into declarative task templates within `academic-orchestrator`.
2. **Eliminate Silent Sample Data Fallbacks**:
   - Delete all instances of `step_conf.get("payload_path") or info["default_sample"]`.
   - If `payload_path` is missing or the target file does not exist, the script must raise `StageDependencyError` immediately and halt with a non-zero exit code.
3. **Refactor into a Pure Execution Runner**:
   - `academic-suite-orchestrator` becomes a deterministic batch execution tool. It accepts an explicit, validated manifest file (`pipeline_manifest.json`) generated by `academic-orchestrator` and runs the CLI scripts sequentially on disk.

```
LEGACY STATE (Anti-Pattern):
User Prompt ──► academic-suite-orchestrator (Skill owns DAG, presets, and silent sample fallbacks)
                     │
                     ▼
             Executes scripts on disk

TARGET ARCHITECTURE (Native Antigravity):
User Prompt ──► digital-saber (Intake & Case Precedent)
                     │
                     ▼
                academic-orchestrator (Builds DAG, verifies prerequisites, manages human gate)
                     │
                     ├─► invoke_subagent(Domain Specialist) ──► Uses Skill ("The Runbook")
                     │                                                │
                     │                                                ▼
                     │                                        Runs CLI Script ("The Hands")
                     │
                     └─► (Optional Batch Execution via academic-suite-orchestrator with explicit manifest)
```

## 3. Skill Deduplication & Consolidation Strategy

The repository currently contains 43 skills, several of which have overlapping capabilities:

### 3.1 Consolidation of Literature Skills
- **Current Skills**: `literature-review` (24 lines), `persian-literature-review-builder` (21 lines), `literature-harvester` (24 lines).
- **Target Consolidation**:
  - `literature-harvester`: Retained for raw database API harvesting (PubMed, CrossRef, SID).
  - `persian-literature-review-builder`: Retained for inverted-triangle literature review synthesis and empirical background tables.
  - `literature-review`: Deprecated and aliased to `persian-literature-review-builder`.

### 3.2 Consolidation of Network Analysis Skills
- **Current Skills**: `network-analysis` (24 lines), `bibliometric-network-analyst` (23 lines), `citation-network-visualizer` (24 lines).
- **Target Consolidation**:

  - `citation-network-visualizer`: Retained for 300-DPI publication graphs and centrality metrics.
  - `network-analysis`: Deprecated as redundant generic wrapper.

## 4. Directive 18 Compliance & Progressive Disclosure

Every `SKILL.md` in `.agents/skills/` must strictly observe single-view budget constraints:
- **Maximum Lines**: 500 lines.
- **Maximum File Size**: 40,000 bytes.
- **Progressive Disclosure Structure**:
  ```
  .agents/skills/<skill-name>/
  ├── SKILL.md                 # Brief overview, trigger conditions, deterministic CLI commands (<= 500 lines)
  ├── scripts/                 # Deterministic Python/R scripts ("The Hands")
  ├── references/              # Detailed schemas, OpenXML XML snippets, deep guidelines
  └── examples/                # Real exemplar payloads and output JSON fixtures
  ```

This ensures that any agent or subagent can view and ingest 100% of a skill specification in a single `view_file` call without truncation or context budget exhaustion.
